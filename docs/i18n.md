# Internationalization (i18n)

next-intl v4 · locales: `vi` (mặc định), `en` · prefix: `always` → `/vi/...`, `/en/...`

## Thêm string dịch

Mọi string hiển thị phải qua next-intl — **không hardcode**.

```ts
// Server Component
const t = await getTranslations("mySection")
// Client Component
const t = useTranslations("mySection")
```

Thêm key vào **cả hai** file trước khi dùng:

```json
// messages/vi.json
{
  "MyFeature": {
    "title": "Tiêu đề",
    "actions": {
      "create": "Tạo mới",
      "delete": "Xóa"
    }
  }
}

// messages/en.json — cùng structure, khác value
{
  "MyFeature": {
    "title": "Title",
    "actions": {
      "create": "Create",
      "delete": "Delete"
    }
  }
}
```

> Thiếu key ở một ngôn ngữ → next-intl throw lỗi. Luôn thêm cả hai file cùng lúc.

## Thêm locale mới

> **Hỏi trước khi làm** — ảnh hưởng đến routing và proxy.

1. Thêm locale vào `src/i18n/config.ts`
2. Tạo file `messages/[locale].json`
3. Kiểm tra `PUBLIC_PATHS` trong `src/proxy.ts` có cần update không
4. next-intl tự xử lý routing qua `defineRouting()`

## Kiểm tra sync

```bash
bash agent-skill/scripts/check-i18n.sh
```

Output JSON với danh sách keys thiếu ở mỗi ngôn ngữ.
