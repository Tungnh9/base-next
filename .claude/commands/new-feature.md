Tôi muốn thêm feature **$ARGUMENTS** vào dự án base-next.

Nếu tôi chưa cung cấp đủ thông tin, hãy hỏi tôi:

- Mô tả: Tính năng này làm gì? User cần gì?
- Scope lần này: sẽ làm gì, không làm gì
- Acceptance criteria cụ thể

Thực hiện theo skill `feature-workflow`:

1. Tạo spec trước khi viết code
2. Hỏi tôi xác nhận spec trước khi tiến hành
3. Implement theo vertical slices, commit sau mỗi slice
